# Cafe Website (HTML/CSS)

This is a front-end structure project for a cafe website, developed as part of my ICT coursework. The focus of this project was to learn and implement the basic structure of a website using HTML.

## 🚀 Key Features
- **Semantic Structure**: Organized using basic HTML tags.
- **Project Scope**: Built as a foundational web development exercise for university ICT.

## 🛠️ Technologies Used
- HTML
- CSS (Basic styling)

## 🎯 Project Goal
To understand web document structure and create a clean, organized layout for a cafe brand.
